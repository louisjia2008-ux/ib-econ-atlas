1. Establish the application shell, legal boundary and toolchain on a feature branch.
2. Define stable content and quiz schemas plus a validator and generated application bundle.
3. Build and hand off the first meaningful study-workspace preview using representative content.
4. Author and validate Unit 1 sections 1.1 through 1.5 as separate atomic content batches.
5. Complete dual navigation, search, scope, study, review, progress, backup, PPC and PWA behavior.
6. Add the unconfigured Cloudflare Worker contract and security tests without live API calls.
7. Add documentation and CI/Pages configuration, then run full automated and browser verification.
8. Write the final acceptance report; leave remote creation, push and deployment blocked on GitHub login and user-authorized external action.

Visual thesis: a dense but calm academic atlas - navy structural chrome, white reading canvas, cobalt data/selection accents and sparing orange assessment cues. The first viewport is the study workspace, not a marketing page.
